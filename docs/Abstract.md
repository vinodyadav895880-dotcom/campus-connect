# CAMPUS CONNECT

## College Placement & Internship Management System

### Abstract

Campus Connect is a web-based College Placement and Internship Management System developed to provide a centralized platform for managing college placement and internship activities.

The system provides separate role-based functionality for three main users: Students, Recruiters and Administrators.

Students can securely login, manage their profile information, view available placement and internship opportunities, apply for suitable jobs, track application status and view scheduled interviews and interview results.

Recruiters can manage job opportunities, view student applications, update application status, shortlist or reject candidates, select candidates and schedule interviews. Recruiters can also view scheduled interviews and update interview results.

Administrators can monitor the overall system through an administrative dashboard. The dashboard provides statistics related to students, recruiters, companies, jobs and applications. Administrators can also view application status statistics, job type distribution and system reports.

The application is developed using Java 21, JSP, Servlets, JDBC, MySQL, Bootstrap 5, Maven and Apache Tomcat 9. The system follows MVC architecture to separate the Model, View and Controller layers.

Security features include BCrypt password hashing, session management, role-based authorization, input validation, prepared statements and environment-based database configuration.

Campus Connect aims to make placement and internship management more organized, centralized and efficient by connecting students, recruiters and administrators through a common web-based platform.
